Jednoduchá ukážka evidencie na poruchy a stroje pre servisné stredisko. Použité technológie: XAMPP, PHP, MySQL, Vue.js. 
vue-tabulka-udajov.jpg      vue-combobox.jpg

Postup na inštaláciu
1- install xampp
2- vytvorit adresar udrzba v htdocs
3- nakopirovanie suborov do adresara udrzba
4- spustit phpmyadmin
5- nad databázou spustiť udrzba.sql
6- vytvorit adresar udrzba/mdbootstrap do ktoreho je potrebne stiahnut akutalnu verziu mdbootstrap
7- vytvoriť adresár udrzba/prilohy do ktoreho sa budu zapisovat pridane prilohy
8- uprava suboru udrzba/config.php - nazov databazy a prihlasovacie udaje k databaze
